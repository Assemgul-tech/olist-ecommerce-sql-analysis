# Olist E-Commerce Insights: Комплексный анализ бизнес-показателей маркетплейса

## 🎯 Цель проекта
Провести глубокий сквозной анализ коммерческих и продуктовых показателей крупнейшего бразильского маркетплейса Olist. На основе исторических данных выявить ключевые точки роста, проанализировать структуру продаж, логистические затраты, финансовое поведение покупателей и эффективность удержания клиентской базы для оптимизации бизнес-стратегии.

## 🛠️ Стек технологий
* **СУБД:** MySQL Server
* **Инструменты:** DBeaver, SQL Workbench
* **Продвинутый SQL:** Обобщенные табличные выражения (CTE), Оконные функции (Window Functions), Многоуровневые подзапросы (Subqueries), Агрегатные функции и условная логика (CASE WHEN).

## 📊 Краткие итоги анализа (Executive Summary)
1. **Масштаб бизнеса:** Успешно доставлено более 96 тысяч заказов, сформировавших многомиллионную выручку. При этом выявлены критические аномалии в данных (декабрь 2016 г.), требующие аудита систем логирования.
2. **Товарные драйверы:** Категория "Красота и здоровье" является абсолютным лидером по выручке, однако "Часы и подарки" обладают скрытым потенциалом за счет высокого среднего чека.
3. **Угроза для маржинальности:** В мебельных категориях стоимость доставки достигает 36% от стоимости товара, что является барьером для роста конверсии.
4. **Финансовый паттерн:** Рынок Бразилии критически зависим от кредитных карт и рассрочки — более 78% оборота обеспечивается транзакциями со средней рассрочкой в 3.5 месяца.
5. **Продуктовый кризис:** Выявлен экстремально высокий уровень оттока клиентов (Churn Rate = 97%). Дана рекомендация по перераспределению бюджета с привлечения (CAC) на удержание (Retention).

## 🛍️ Блок 2. Товарная аналитика (Product Analytics)

### Запрос: Топ-5 категорий товаров по объему выручки (с переводом на английский)
```sql
SELECT 
    t.product_category_name_english AS category_name,
    COUNT(DISTINCT o.order_id) AS orders_count,
    ROUND(SUM(i.price), 2) AS total_revenue
FROM olist_orders o
    JOIN olist_order_items i ON o.order_id = i.order_id
    JOIN olist_products p ON i.product_id = p.product_id
    JOIN olist_category_translation t ON p.product_category_name = t.product_category_name
WHERE o.order_status = 'delivered'
GROUP BY category_name
ORDER BY total_revenue DESC
LIMIT 5;
```

### 📊 Результаты выборки:

| Категория | Кол-во заказов | Общая выручка (R$) |
| :--- | :--- | :--- |
| health_beauty | 8,647 | 1,233,131.72 |
| watches_gifts | 5,495 | 1,166,176.98 |
| bed_bath_table | 9,272 | 1,023,434.76 |
| sports_leisure | 7,530 | 954,852.55 |
| computers_accessories | 6,530 | 888,724.61 |

### 💡 Аналитический инсайт (Выводы для бизнеса):
* **Лидер по выручке:** Категория `health_beauty` занимает 1-е место, генерируя наибольший объем денежного потока для маркетплейса.
* **Скрытый потенциал высокого чека:** Обратите внимание на категорию `watches_gifts`. По количеству заказов она находится на последнем месте в Топ-5 (всего 5 495 заказов), но за счет высокого среднего чека она занимает уверенное 2-е место по выручке. Маркетологам стоит инвестировать в рекламу именно этой категории, так как привлечение одного клиента здесь принесет компании больше прибыли, чем в категории `bed_bath_table` с её более дешевыми товарами.

### Запрос 2.2: Топ-5 категорий товаров с самой дорогой средней стоимостью доставки

SELECT 
    t.product_category_name_english AS category_name,
    ROUND(AVG(i.freight_value), 2) AS avg_freight_cost,
    ROUND(AVG(i.price), 2) AS avg_item_price
FROM olist_orders o
    JOIN olist_order_items i ON o.order_id = i.order_id
    JOIN olist_products p ON i.product_id = p.product_id
    JOIN olist_category_translation t ON p.product_category_name = t.product_category_name
WHERE o.order_status = 'delivered'
GROUP BY category_name
ORDER BY avg_freight_cost DESC
LIMIT 5;

1. computers: доставка = 48.57 R$ (ср. цена товара = 1,098.92 R$)
2. home_appliances_2: доставка = 44.39 R$ (ср. цена товара = 467.33 R$)
3. furniture_mattress_and_upholstery: доставка = 42.74 R$ (ср. цена товара = 116.85 R$)
4. kitchen_dining_laundry_garden_furniture: доставка = 42.12 R$ (ср. цена товара = 166.18 R$)

### 💡 Аналитический инсайт (Выводы для бизнеса):
* Логично, что крупногабаритная техника и мебель занимают верхние строчки из-за веса и объёма. 
* Критическая зона риска — это категория №3 `furniture_mattress_and_upholstery` (Матрасы и мягкая мебель). Обратите внимание: при средней цене самого товара в 116.85 R$, доставка обходится клиенту аж в 42.74 R$! Это почти 36% от стоимости покупки. Бизнесу стоит пересмотреть логистические тарифы на мебель, так как столь дорогая доставка сильно снижает конверсию в покупку.

SELECT 
    payment_type,

## 👥 Блок 4. Географический анализ (Где наши лучшие клиенты?)

### Запрос 4.1: Топ-5 штатов Бразилии по объему выручки и среднему чеку
```sql
SELECT 
    c.customer_state AS state,
    COUNT(DISTINCT o.order_id) AS total_orders,
    ROUND(SUM(i.price), 2) AS total_revenue,
    ROUND(SUM(i.price) / COUNT(DISTINCT o.order_id), 2) AS avg_order_value
FROM olist_orders o
    JOIN olist_order_items i ON o.order_id = i.order_id
    JOIN olist_customers c ON o.customer_id = c.customer_id
WHERE o.order_status = 'delivered'
GROUP BY state
ORDER BY total_revenue DESC
LIMIT 5;
```

### 📊 Результаты выборки:

| Штат (Код) | Всего заказов | Общая выручка (R$) | Средний чек (R$) |
| :--- | :--- | :--- | :--- |
| SP (Сан-Паулу) | 40,501 | 5,067,633.16 | 125.12 |
| RJ (Рио-де-Жанейро) | 12,350 | 1,759,651.13 | 142.48 |
| MG (Минас-Жерайс) | 11,354 | 1,552,481.83 | 136.73 |
| RS (Риу-Гранди-ду-Сул) | 5,345 | 728,897.47 | 136.37 |
| PR (Парана) | 4,923 | 666,063.51 | 135.30 |

### 💡 Аналитический инсайт (Выводы для бизнеса):
* **Абсолютный лидер:** Штат Сан-Паулу (SP) является главным экономическим ядром маркетплейса, генерируя почти половину всех заказов из Топ-5. Это ключевой регион присутствия.
* **Потенциал регионов:** В штате Рио-де-Жанейро (RJ) средний чек заметно выше (142.48 R$), чем в Сан-Паулу. Это означает, что там покупают более дорогие товары или более крупными корзинами. 
* **Рекомендация для бизнеса:** Логистическому отделу следует сфокусироваться на открытии распределительных центров (складов) в штате SP для обеспечения сверхбыстрой (возможно, за 1 день) доставки, так как плотность заказов это окупает. А отделу маркетинга стоит запустить таргетированную рекламу премиальных товаров на штат RJ, где клиенты готовы тратить больше за один раз.

## 👥 Блок 5. Продуктовые метрики и продвинутый SQL

### Запрос 5.1: Нарастающий итог выручки по месяцам (Оконные функции + CTE)
```sql
WITH monthly_sales AS (
    SELECT 
        DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m') AS sales_month,
        ROUND(SUM(i.price), 2) AS revenue
    FROM olist_orders o
        JOIN olist_order_items i ON o.order_id = i.order_id
    WHERE o.order_status = 'delivered'
    GROUP BY sales_month
)
SELECT 
    sales_month,
    revenue,
    ROUND(SUM(revenue) OVER (ORDER BY sales_month), 2) AS running_total_revenue
FROM monthly_sales
ORDER BY sales_month;
```

### 📊 Результаты выборки (Первый год компании):
* 2016-09: Выручка = 134.97 R$ | Нарастающий итог = 134.97 R$
* 2016-10: Выручка = 40,325.11 R$ | Нарастающий итог = 40,460.08 R$
* ...
* 2017-01: Выручка = 111,798.36 R$ | Нарастающий итог = 152,292.34 R$
* 2017-05: Выручка = 489,338.25 R$ | Нарастающий итог = 1,575,699.52 R$
* 2017-09: Выручка = 607,399.67 R$ | Нарастающий итог = 3,641,326.78 R$

### 💡 Аналитический инсайт (Выводы для бизнеса):
* **Анализ темпов роста (MoM):** Из графика нарастающего итога видно стабильное экспоненциальное ускорение бизнеса на стыке 2016 и 2017 годов. Ключевой переломный момент — январь 2017 года, когда ежемесячная выручка маркетплейса впервые пробила отметку в 100 000 R$.
* **Аномалии в данных:** Обратите внимание на декабрь 2016 года (`2016-12`) — выручка падает практически до нуля (10.9 R\$). Это классическая аномалия, которая требует немедленного расследования аналитика: была ли это техническая поломка сбора данных на стороне базы, сбой платежного шлюза или компания временно приостанавливала операции. В отчете для директора этот месяц нужно обязательно подсветить.

### Запрос 5.2: Анализ частоты покупок и оценка риска оттока (Churn Risk)
```sql
WITH customer_orders_count AS (
    SELECT 
        c.customer_unique_id,
        COUNT(DISTINCT o.order_id) AS orders_qty
    FROM olist_orders o
        JOIN olist_customers c ON o.customer_id = c.customer_id
    WHERE o.order_status = 'delivered'
    GROUP BY c.customer_unique_id
)
SELECT 
    CASE 
        WHEN orders_qty = 1 THEN 'Одноразовые клиенты (Churn Risk)'
        WHEN orders_qty = 2 THEN 'Повторные клиенты (Loyal-2)'
        ELSE 'Постоянные клиенты (VIP 3+)'
    END AS customer_segment,
    COUNT(*) AS total_customers,
    ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER(), 2) AS share_percentage
FROM customer_orders_count
GROUP BY customer_segment;
```

### 📊 Результаты выборки:

| Сегмент клиента | Кол-во клиентов | Доля рынка (%) |
| :--- | :--- | :--- |
| Одноразовые клиенты (Churn Risk) | 90,557 | 97.00% |
| Повторные клиенты (Loyal-2) | 2,573 | 2.76% |
| Постоянные клиенты (VIP 3+) | 228 | 0.24% |

### 💡 Аналитический инсайт (Выводы для бизнеса):
* **Критический уровень оттока:** 97% покупателей делают один заказ и уходят. Это говорит о том, что маркетплейс тратит огромные бюджеты на маркетинг и привлечение клиентов (**CAC** — Customer Acquisition Cost), но не может удержать их. С такой метрикой пожизненная ценность клиента (**LTV** — Lifetime Value) остается крайне низкой.
* **Рекомендация для бизнеса:** Руководству компании нужно срочно сместить фокус с привлечения новых пользователей на удержание старых (запустить Retention-кампании). Необходимо внедрить систему триггерных email-рассылок, персонализированные скидки на вторую покупку, запустить программу лояльности или кэшбек. Повышение доли повторных клиентов хотя бы с 3% до 6% способно удвоить выручку компании без увеличения затрат на платную рекламу.
